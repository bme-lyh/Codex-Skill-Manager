Codex Skill Manager release notice / 发布说明

These Windows binaries are not code-signed. Windows SmartScreen may show a
warning. Download releases only from:
https://github.com/bme-lyh/Codex-Skill-Manager/releases

Verify the downloaded ZIP before opening it:
  Get-FileHash .\DOWNLOADED_ARCHIVE.zip -Algorithm SHA256

Compare the result with the matching line in the release SHA256SUMS file.
The checksum detects a changed or damaged download; it is not a code signature.
