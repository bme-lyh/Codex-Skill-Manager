# GUI 指南

统一桌面界面包含五项一级导航：**首页、资产、安全、活动、设置**。资产和活动提供
二级标签页。**添加项目**对所有来源使用同一条四步流程，先运行必选的本地检查，
再决定是否使用可选的 Codex 能力。写入前请核对实际目标、权限和恢复方式；Critical
风险不可忽略，High 风险必须逐簇确认并填写非空原因。

## 导航

侧栏顶部的目录选择器用于切换 **Codex Skills** 与 **Agents Skills**。列表、分组、
安全、更新、历史和隔离区会跟随当前目录过滤。侧栏可以收起；界面明暗、强调色与
高对比模式跟随 Windows 设置。

- **首页**：显示已管理、未管理和系统 Skills、待处理报告、来源分组和最近操作。
- **资产**：包含 **Skills** 和 **分组**。
- **安全**：包含本地 Skill 扫描和风险复核结果。
- **活动**：包含 **更新**、**历史与回滚**、**隔离区** 和 **报告**。
- **设置**：包含语言、存储、GitHub、定时检查、可选 Codex 复核和诊断。

主界面的顶部操作可随时打开 **添加项目**。旧 Page 路由和 Wails/API 兼容边界仍为
已有集成保留；面向用户的界面术语以本指南为准。

## 首页

首页是状态总览，不是另一条安装入口。它汇总 Skills 管理状态、只读系统 Skills、
未处理安全报告、来源分组，以及最近的安装、更新、管理和回滚活动。

## 资产

### Skills

可以搜索并查看来源、状态、版本和本地修改。支持全选、反选和清空当前结果。选中的
未管理 Skills 可以分析和管理；选中的个人 Skills 可以移至 **隔离区**；系统 Skills
不可选择。

管理已有 Skill 时，应用会先生成只读的来源与安全计划。确认后只记录来源信息和哈希，
不会移动或改写 Skill 内容。来源会按可信目录、`SKILL.md` 显式来源、Git remote 和
GitHub 链接识别；无法确认的远程来源会保留在独立的本地分组中。

### 分组

真实来源分组仍是更新的依据。显示用的分组可以新建、改名、排序，也可以通过拖动
Skills 调整成员。布局变化会记录事务并可回滚，不会改变 Skill 的真实来源或内容。

## 添加项目

窗口显示四个步骤：

1. **来源**：输入 GitHub 仓库、目录或 `SKILL.md` 链接，也可以输入包含一个或多个
   Skill 的绝对本地目录，并选择要写入的 Skills 目录。GitHub 来源会解析到完整 Commit；本地目录会先复制到有边界、
   由应用管理的快照。
2. **理解与计划**：自动读取项目说明和安装标记，判断项目类型，发现 Codex Skills，
   盘点来源，并检查实际写入目标。检查按必选、条件触发和可选分组；这一阶段不会调用
   Codex、下载依赖或执行仓库脚本。
3. **检查与确认**：查看项目类型、证据、Skill 选择、具体目标、风险、权限和可恢复性。
   结论有四种：**可安装**、**需要确认**、**已阻止**、**检查未完成**。只有前两种
   可以继续，后两种会安全停止。
4. **安装与结果**：应用选中的 Skills 或已批准的结构化步骤，显示进度和活动，记录
   事务，并在变更后重新读取最新 Skills 与操作状态。结果会保留事务 ID、完成目标、
   人工步骤和恢复状态。

目标目录属于计划的一部分。进入检查步骤后不能临时换目录；如需更改，请返回来源步骤
重新分析。同名 Skill 可以分别存在于两个目录，批量操作不会跨目录执行。

入口不会要求用户选择安装模式。复杂仓库的 **运行增强项目扫描** 位于 **更多选项**；
它是 Codex 提供的可选语义扫描，不是独立安装模式。扫描复用本地评估，以关闭 Shell
的方式发送有边界的来源上下文，返回项目概述、安全结论、证据限制和声明式安装方式。
扫描本身不会授权安装、生成计划或下载依赖；阅读结果并点击 **同意并生成安装计划**
后，Codex 才会提出结构化步骤和权限。

应用不会把 Codex 文本当作命令运行。自动步骤仅限于安装选中的 Skills、从官方 PyPI
安装与仓库匹配的固定版本 Python 工具，以及为受管工具写入 Codex MCP 配置。仓库脚本、
任意 Shell 命令、不支持的包管理器和其他内容都保留为人工步骤。受管 Python 工具和
MCP 自动集成需要 GitHub 来源以核对包归属；MCP 目标必须是真实且明确选择的 Git 或
SVN 项目目录，也不会覆盖已有同名配置。

如果批准的计划包含 Python 工具，计划生成时会从官方 PyPI 将完整 Wheel 依赖下载到
隔离暂存区，并锁定文件名和 SHA256。分析阶段不会安装或运行它们；源码包会被拒绝，
含本机代码的 Wheel 需要单独的 High 风险批准。执行只使用已经核验的锁定文件。

执行前必须批准所有必需权限。长任务可以隐藏窗口并在后台继续，重新打开会恢复最新进度。
若 Codex 无法生成可靠计划，来源评估、风险结果和 Skill 选择仍可保留。
**更多选项**中也提供 **切换标准安装**，它只写入选中的 Skill 目录，不配置 MCP 或额外依赖。

失败或取消时，应用会按逆序恢复已完成的可逆步骤；部分完成的结果会保留人工步骤和回滚
入口。安装实际完成但界面刷新失败时，结果仍会保留，应重试刷新，不要重复安装。若目标
在安装后被外部修改，回滚不会强行覆盖，并会给出人工恢复路径。请在 **历史与回滚**
中处理事务，在 **隔离区** 中恢复已移除的 Skills。

## 安全

没有可信扫描记录或内容发生变化的 Skills 默认选中。结果按 **分组 → Skill → 警告**
展示，大型报告默认折叠细节。安全红点统计每个目标最新有效报告中的唯一 High/Critical
待处理命中，不会因重复扫描而累加。

Critical 风险始终阻止写入且不可忽略。High 风险必须逐簇确认并填写非空原因，批量操作
不能绕过这条规则；Medium 及以下风险使用普通忽略流程。恢复之前接受的 High 簇后，
它会立即重新进入门禁。

安全页的可选 **Codex 复核** 会在关闭 Shell 的情况下按分组提供建议，只作为辅助证据，
最终决定仍由用户作出。设置页的启用开关只控制安全页复核，不会悄悄启用添加项目扫描。

## 活动

### 更新

更新页比较来源 Commit，并为每个来源显示状态和上次检查时间。应用前请核对不可变
Commit、实际目标、风险结果和 Skill 选择。每个来源都是独立事务，有自己的备份和回滚
入口；某个来源失败不会隐藏其他已完成结果。定时检查只读，不会自动安装更新。

### 历史与回滚

历史页显示事务 ID、目标、状态、进度和恢复信息。有备份时可以回滚；如果目标在安装后
发生变化，恢复会安全停止，而不是覆盖外部修改。

### 隔离区和报告

隔离区保存明确移除的个人 Skills，不执行永久删除，并支持恢复。报告页提供本地扫描和
操作的可读审计记录及结构化记录。

## 设置

“语言”支持简体中文和 English。首次运行以及没有保存语言的旧配置默认使用中文；切换
语言会立即生效、自动保存，并在下次启动恢复。

可以配置绝对路径、定时只读检查、私有 GitHub 凭据、可选的安全页 Codex 复核和诊断。
凭据保存在 Windows 凭据管理器，不写入日志或报告。Codex 状态区域检查 CLI 路径、
登录状态、能力和当前可见的模型目录；Codex 需要已安装且已登录的 CLI，并会消耗账户额度。
