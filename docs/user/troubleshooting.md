# 故障排查

先做三件事：使用最新发布包，运行 `csm doctor`，并保留错误文字、事务 ID 和最新日志。
每个来源都会先通过必选的本地分层检查；增强项目扫描是可选的。

## 启动后窗口全白或无法打开

- 确认 Windows 10/11 已安装 WebView2 Runtime；
- 运行 `csm doctor`；
- 检查设置中的数据目录是否可写；
- 仍然无法加载时，保留提示文字和 `data/logs` 下的最新日志。

## 私有仓库返回 401/404

- 运行 `gh auth status`；
- 确认凭据具备读取仓库内容的权限；
- 私有仓库存在但当前凭据无权访问时，GitHub 可能返回 404。

## 添加项目返回 GitHub 403

打开 **设置 → GitHub 连接**，验证当前凭据。如果页面显示恢复时间，请等待倒计时
结束后再重试。**添加项目**会保留来源输入和本地分析状态；GitHub 暂时不可用时，
可以改用已经下载好的本地目录。

## 结论显示“已阻止”或“检查未完成”

四种结论是 **可安装、需要确认、已阻止、检查未完成**：

- **需要确认**：必选检查已经完成，但仍有标出的项目需要人工确认；
- **已阻止**：本地安全策略或不支持的目标禁止写入，请查看证据或更换来源；
- **检查未完成**：必需的覆盖范围或证据不足，请解决来源或扫描限制后重新点击
  **检查项目**。

只有“可安装”和“需要确认”可以继续。必选本地检查未完成时，不会因此开放 Codex
扫描或依赖计划。

## 增强项目扫描不可用

- 在 **设置** 中检查 Codex CLI 路径、登录状态、能力和可见模型；
- 确认账户有可用额度；
- 私有来源应确认允许 Codex CLI 处理其内容；
- MCP 计划需要真实的 Git 或 SVN 项目目录，不能使用暂存目录或链接；
- 在首屏重试 **Codex 审核**，或保留本地评估并选择 **标准 Skill 安装**。

Codex 是可选能力。语义扫描无法生成可靠结果时，本地评估和已选 Skills 仍然可用。

## 安装完成但列表没有更新

如果安装后的界面刷新失败，实际结果和事务仍会保留。请按窗口提示重试刷新，不要再次
执行安装；刷新后确认最新 Skills 和操作状态。

## 安装或回滚中断

查看 **添加项目** 窗口或 **活动 → 历史与回滚** 中的时间线和恢复状态。失败或取消时，
应用会先按逆序恢复已完成的可逆步骤。恢复不完整时，使用记录的回滚入口并保留事务 ID。
不要手动移动或删除备份路径。

如果其他程序在安装后修改了受管文件，自动回滚会拒绝覆盖这些修改，并显示人工恢复
路径。标为“手动”的步骤从未由应用执行，不属于自动回滚范围。

## Skill 无法更新

- 检查是否存在本地修改；
- 检查来源锁中的仓库、路径和 ref；
- 重新生成计划，不要复用过期的 plan ID。

对于已记录的失败事务，可以运行：

```powershell
csm rollback --transaction <ID>
```
